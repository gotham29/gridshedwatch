Reference methods

Eleven methods, from a rule an operator could write to a foundation model

Rules and statistics

  • Operator-style rule: demand above its forecast for 3 hours
  • Seasonal z-score: unusual for the time of year
  • CUSUM: small, steady deviations that add up
  • Critical slowing down: a system near a tipping point swings more and recovers slower

Forecasters

Predict the next hour and alert on large misses: LightGBM (gradient-boosted trees), LSTM, PatchTST (a transformer), Chronos-Bolt (a pretrained time-series model)

Detectors

Sub-PCA: patterns unlike past ones. HTM: learns sequences and flags surprises

Floor

Random scores: what pure luck achieves at the same alert rate

All see the same five signals; learned models fit on 2019 only; settings are published defaults, none tuned on events

Details: operator rule = demand above its day-ahead forecast by more than the trailing year’s percentile of forecast error. Z-score = each signal against its past-30-day median and MAD. CUSUM = two-sided, k 0.5, reset at h 5, on robust deviations. Critical slowing down = rolling 168 h variance and lag-1 autocorrelation (the classic early-warning indicators). Forecasters scored by absolute next-hour error, turned into causal percentiles: LSTM 2×64, 24 h input; PatchTST 168 h input, small-model defaults; LightGBM on hourly, weekly and calendar lags; Chronos-Bolt small, 512 h context, zero-shot (pretraining may include EIA-930: possible contamination, all events predate it). Sub-PCA = PCA reconstruction error on 24 h windows, TSB-AD defaults. HTM = one temporal memory per signal via htm-monitor, anomaly likelihood, trained on 2019 then frozen. Seeds: 5 for LSTM, PatchTST, LightGBM, HTM, random. Disclosure: HTM is run through htm-monitor, software I develop as an HTM practitioner (HTM itself comes from Numenta’s research), scored by the same code; the shared alert rules were first developed on HTM’s output on three development events. Checks that this didn’t favour HTM: alternative rules (any signal; forecast error only) and HTM’s other learning setups are in the appendix; HTM’s online setup scores 6.4 watches vs 6.0 for the entry. Refitting LightGBM every year leaves it at 7.2 watches.
